# 🌐 Personal Portfolio Website

## 📖 Project Overview

This is a single-page responsive portfolio website created as part of a lab assignment (HCI Lab: Build and Test a Single-Page Responsive Portfolio). The website showcases my personal information, education and experience, skills, projects, and contact details. It is built using HTML and CSS.

## 🎯 Purpose

The goal of this project is to:

* Practice responsive web design using HTML5 and CSS3
* Learn how to structure, style, and organize a single-page website
* Build a professional personal brand that showcases my background, skills, experience, and projects
* Present my interest in Data Science and Quantitative Finance as potential career directions
* Provide recruiters and other visitors with an overview of my profile and a way to contact me

## 👥 Target Audience

This portfolio is designed for:

* Potential employers and recruiters interested in my academic background, technical foundations, and projects
* Academic supervisors and lecturers who want to learn more about my interests and development
* Students and professionals interested in programming, data analysis, and technology

## 🧱 Technologies Used

* HTML5 (semantic elements: `header`, `nav`, `main`, `section`, `article`, `footer`)
* CSS3 (Flexbox, Box Model, Media Queries, hover effects, and transitions)
* Poppins font from Google Fonts
* Icons from Boxicons (inline SVG)

## 📐 Layout & Sections

The website includes the following sections:

* Header – Name and navigation menu
* Home – Introduction, tagline, and buttons
* About Me – Short bio
* Experience & Education – Timeline of my experience and education
* Skills – Technical and non-technical skills
* Featured Project – List of projects with descriptions, technologies used, and links
* Contact – Email, LinkedIn, and GitHub
* Footer – Copyright

## 📱 Responsiveness

The site is optimized for:

* Desktop
* Tablet
* Mobile

Responsive design is achieved using media queries, relative units (`em`, `rem`, `%`, `vh`, `vw`), and flexible layouts.

* **Desktop and tablet:** same layout (screen width wider than 48em, about 768px).
* **Mobile (48em or smaller):** one-column layout. The hero image becomes a banner, the navigation menu moves to its own row, the Education timeline switches to a left-right zigzag, and a back-to-top button appears.

## 🎨 UI/UX Considerations

* **Readable colors:** text and background colors were checked with the WCAG contrast ratio. Main text on the background is 16.1:1, gray text is 8.9:1, and dark text on the teal buttons is 11.5:1 (the minimum recommended for normal text is 4.5:1).
* **Consistent project cards:** the project cards use the same dark box and teal accent as the rest of the website. In an earlier version they were gray, and the teal tags were hard to see on them (contrast 1.7:1).
* **Navigation:** the menu stays at the top on desktop, section titles are not hidden under it when a menu link is clicked, links change color on hover, and there is a visible outline when navigating with the keyboard (Tab key). On mobile there is a back-to-top button.
* **Readability:** the text is left-aligned instead of justified, so the spacing between words stays even in narrow cards.
* **Feedback:** buttons, cards, tags, and links have hover effects with smooth transitions, so users can see what is clickable.

## 🧪 How to Run Locally

1. Open your code editor (e.g., Visual Studio Code, etc.).
2. In your code editor, open the terminal.
3. Clone the repository:

```
git clone https://github.com/rodriegooo/My-Portfolio-Website
```

4. Open index.html in your browser, or run the website locally using the Live Server Extension.

An internet connection is needed to load the Poppins font from Google Fonts.
